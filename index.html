Möbel

Namn
Anteckning
Dra en möbel för att flytta den. R vrider 90°, Q/E 15°, Delete tar bort, piltangenter knuffar. Dra i golvet för att snurra vyn, högerklick-dra för att panorera, scrolla för zoom.
HallVirtuell visning
Klicka för att gå dit
WASD eller piltangenter för att gå, Shift springer. Dra i bilden för att titta runt. Dubbelklicka på golvet för att gå dit. Möbler kan fortfarande dras.
